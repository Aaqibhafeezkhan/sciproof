## 1. Quick Verification (For Reviewers)

Reviewers can verify the complete paper artifacts in **under 2 minutes** without setting up complex external databases or accounts:

```bash

pip install sciproof

# 2. Check evidence integrity (offline, instant)
sciproof verify baseline.sciproof.json

# 3. (Optional) Re-execute the experiment and verify within tolerances
sciproof verify baseline.sciproof.json --rerun --yes
```

## 3. LaTeX Integration (Zero Copy-Paste Error)

The paper manuscript imports numbers directly from the verified manifest:

```bash

  --value accuracy out/metrics.json "$.accuracy" \
  --value fone out/metrics.json "$.f1_score"
```
